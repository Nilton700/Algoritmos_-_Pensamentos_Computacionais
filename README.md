# 🧮 Calculadora de 20 Operações Matemáticas — Flowgorithm

> Projeto acadêmico desenvolvido para a disciplina de **Algoritmos e Pensamentos Computacionais**, utilizando a ferramenta **Flowgorithm** para criação e representação de algoritmos por meio de fluxogramas.

---

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma **calculadora com 20 operações matemáticas**, implementada no **Flowgorithm**.

A proposta do trabalho é aplicar conceitos fundamentais de **lógica de programação, estruturas condicionais, estruturas de repetição, variáveis, operadores matemáticos, entrada e saída de dados e funções matemáticas**.

O usuário pode selecionar uma operação por meio de um menu e informar os valores necessários para que o algoritmo realize o cálculo e apresente o resultado.

O projeto foi desenvolvido como uma atividade prática para demonstrar a aplicação dos conceitos estudados na disciplina de **Algoritmos e Pensamentos Computacionais**.

---

## 🎯 Objetivos

* Desenvolver o raciocínio lógico e o pensamento computacional;

## 🛠️ Ferramenta Utilizada

### Flowgorithm

O projeto foi desenvolvido utilizando o **Flowgorithm**, uma ferramenta voltada para o aprendizado de programação e lógica computacional por meio da criação de **fluxogramas**.

## ⚙️ Funcionamento

Ao iniciar a calculadora, o usuário encontra um **menu de operações**.

O funcionamento geral segue o seguinte fluxo:

```text
Início
  ↓
Exibição do menu
  ↓
Usuário escolhe uma operação
  ↓
Entrada dos valores necessários
  ↓
Processamento do cálculo
  ↓
Exibição do resultado
  ↓
Retorno ao menu
  ↓
Nova operação ou encerramento
  ↓
Fim
```

Cada operação possui sua própria lógica de processamento, sendo que algumas exigem apenas um valor e outras necessitam de dois ou mais valores.

## 📐 Exemplos de Operações

### Adição

Realiza a soma entre dois números:

```text
Resultado = Número 1 + Número 2
```

### Potenciação

Eleva um número a uma determinada potência:

```text
Resultado = Base ^ Expoente
```

### Aumento Percentual

Aplica um percentual de aumento sobre determinado valor:

```text
Resultado = Valor + (Valor × Percentual / 100)
```

### Desconto Percentual

Aplica um desconto percentual:

```text
Resultado = Valor - (Valor × Percentual / 100)
```

### Conversão Celsius → Fahrenheit

```text
Fahrenheit = (Celsius × 9 / 5) + 32
```

### Conversão Fahrenheit → Celsius

```text
Celsius = (Fahrenheit - 32) × 5 / 9
```

## ▶️ Como Executar

Para executar o projeto, é necessário ter o **Flowgorithm** instalado.

1. Faça o download ou clone este repositório;
2. Abra o arquivo `.fprg` no Flowgorithm;
3. Execute o fluxograma;
4. Escolha uma das 20 operações disponíveis;
5. Informe os valores solicitados;
6. Confira o resultado apresentado pelo algoritmo
.
